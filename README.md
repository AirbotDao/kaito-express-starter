
# Kaito Express Starter 🚀

A minimal **Express API starter project** to kick off Node.js development with GitHub Actions CI.

## Features
- Express server
- Basic route (`GET /`)
- Jest testing setup
- GitHub Actions workflow
- `.env.example`

## Setup
```bash
git clone https://github.com/YOUR_USERNAME/kaito-express-starter.git
cd kaito-express-starter
npm install
npm run dev
